# Known Limitations & External Service Dependencies

1. **Independent Concept Scope**:
   - This web application is an independent creative proposal and portfolio project. Official artist endorsement or direct representation by Ayo Maff or EMPIRE has not yet been formalized.
2. **Audio Licensing**:
   - To respect copyright law, full-length commercially licensed master recordings are not bundled in repository storage. Instead, audio visualization operates on royalty-free Afrobeats stems and authorized audio preview snippets, accompanied by direct deep-links to official streaming services (Spotify, Apple Music, Audiomack, YouTube).
3. **E-Commerce & Payment Gateway**:
   - The merchandise store is currently in conceptual demonstration mode with a fully implemented client and server checkout architecture ready to be connected to live Paystack API keys. Actual monetary transactions are disabled until merchant authorization is configured.
4. **Tour Ticketing**:
   - Live show dates represent verified and proposed festival/headline appearances. Ticket purchase triggers link to legitimate event platforms (e.g. Livespot, O2 Academy, Ticketmaster).
